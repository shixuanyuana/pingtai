# 赛事云导播接口自动化平台

本地运行的接口自动化管理平台。用例按照页面业务结构组织：

```text
直播管理
├─ 直播预约（7 个内置接口）
├─ 直播列表（6 个内置接口）
└─ 直播订单（6 个内置接口）
```

页面左侧可以切换目录，每个目录只显示属于自己的接口用例。新增用例时也可以选择保存到哪个目录。

## 主要功能

- 测试环境和真实环境切换
- 独立的“账号与登录”页面，按环境持久化账号、密码摘要和 Token
- Token 按 12 小时有效期管理，页面打开及接口执行时自动检查并刷新
- 按业务目录同步、查看和执行接口用例
- 独立的“新增接口用例”页面，创建时选择业务目录，保存后跳转到对应目录
- 每条用例提供“查看结果”，展示请求地址、HTTP 状态码、耗时、断言明细和原始响应
- 支持 `{{变量名}}` 环境变量占位符
- 对 GET 查询接口执行目录套件
- 写入类接口执行前二次确认
- 记录最近 100 次运行结果

## 启动

```powershell
py -m pip install -r requirements.txt
py run.py
```

浏览器打开 <http://127.0.0.1:8000>。

首次进入某个目录时，点击“同步当前目录接口”即可生成或更新该目录的内置用例。

## 目录

- `app/main.py`：FastAPI 后端、数据库、接口模板和用例执行逻辑
- `web/index.html`：前端管理页面
- `data/platform.db`：运行后生成的 SQLite 数据库
- `run.py`：启动入口
- `smoke_test.py`：基础冒烟测试

请勿将账号、密码、Token 或优惠券码提交到 Git。
登录资料只保存在本机 `data/platform.db` 中，`data/` 已被 `.gitignore` 排除。虽然不保存明文密码，密码摘要仍属于敏感数据，请勿分享该数据库文件。
